================================================================================
TROUBLESHOOTING
================================================================================

If tests fail:

1. Check Stata version:
   - Minimum: Stata 16.0
   - Recommended: Stata 18.0+

2. Check adopath:
   - Run: adopath
   - Ensure "../ado" is included

3. Check file permissions:
   - Tests need read/write access for temp files

4. Check random seed:
   - Results may vary slightly due to randomness
   - Acceptable if within reported ranges

5. Check for conflicts:
   - Other ssiv installation in adopath?
   - Run: which ssiv

6. Re-run individual failing tests:
   - cd tests
   - do test_[name].do
   - Check detailed output

Common Issues:
--------------
Issue: "command ssiv not found"
Fix: adopath + "../ado"

Issue: "file not found"
Fix: Ensure you're in tests/ directory

Issue: Tests pass but results outside ranges
Fix: This is OK - sampling variation expected

Issue: One test fails consistently
Fix: Check individual test file for issues
     May be Stata version specific
